### Slide/Página 1
Projeto Mobile + Prova Oral (4° Bimestre)
Este trabalho consiste no desenvolvimento de uma aplicação mobile completa,
aplicando os conceitos abordados ao longo do bimestre. O trabalho deverá ser realizado
em duplas. Cada dupla deverá definir um tema próprio para a aplicação, diferente do
exemplo “Gerenciamento de Clientes” desenvolvido em aula. O tema pode ser o mesmo
desenvolvido no Projeto Web e deve atender aos requisitos apresentados a seguir.
Requisitos Funcionais (mínimos)
1. Cadastro de registros: inserir novos dados, definindo campos obrigatórios e op-
cionais.
2. Listagem de registros: exibir os itens em uma FlatList, com os campos do tema
escolhido.
3. Edição/Atualização: permitir a alteração de um registro existente.
4. Exclusão: remover um registro individualmente.
5. Pesquisa: permitir a busca de um registro por um campo-chave (por exemplo:
título, nome, código, e-mail, ID, ...).
6. Ordenação: permitir ordenar a listagem com base em um campo do tema escolhido
(por exemplo: nome, data, preço, ...), em ordem crescente e decrescente.
Requisitos Técnicos
• Back-end: Java + Spring Boot.
• Front-end: React Native + Expo. Os estilos devem ser aplicados com StyleSheet
e a navegação entre telas deve ser implementada com React Navigation.
• Persistência: JPA/Hibernate + MySQL.
• Controle de versão: GitHub.
• Tratamento de erros: exibir mensagens de sucesso/erro no front-end. Exemplos:
registro não encontrado, erros de validação, operações bem-sucedidas, ...
• Organizaçãoemcamadas(back-end): model, repository, service e controller.
Entrega
• Responsável pela entrega: apenas um integrante da dupla deve realizar a sub-
missão no Classroom. O outro deve apenas marcar o trabalho como entregue.
• O que entregar:
– Arquivo compactado do back-end, nomeado como
ProjetoMobile_Backend_Nome1_Nome2.zip.

• Prazo: conforme divulgado no Classroom. Após a data final de entrega, não serão
aceitas modificações na implementação até a data da prova oral.
Prova Oral
• Data e horário: conforme cronograma disponibilizado em anexo no Classroom.
• Durante a avaliação, a dupla deverá demonstrar o funcionamento de todas as funci-
onalidades e a conformidade com os requisitos técnicos.
• Ambos os integrantes devem participar ativamente da apresentação. Qualquer in-
tegrante poderá ser questionado individualmente sobre qualquer parte do projeto,
incluindo questões teóricas e de desenvolvimento abordadas em aula.
Informações Importantes
• Serão avaliados: funcionamento da aplicação, código limpo, uso adequado das fer-
ramentas, versionamento (histórico de commits no GitHub) e domínio técnico de-
monstrado na prova oral.
• A consulta a documentações oficiais, livros e demais fontes externas é permitida,
desde que a implementação seja de elaboração própria da dupla.
• A utilização de framework ou biblioteca diferente daquelas abordadas em aula deve
ser previamente consultada com o professor.
• Semelhanças significativas de código entre duplas resultarão em nota zero
para todos os envolvidos.
